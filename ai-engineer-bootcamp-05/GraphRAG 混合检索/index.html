01 · 向量检索的局限

1纯向量检索的两类失效场景

向量检索用余弦相似度衡量语义距离，擅长"模糊语义匹配"，但在两类场景下系统性失效：

失效类型 A：精确匹配

  • 查询："合同编号 CN-2024-00847"
  • 向量搜索找不到精确的 ID 字符串
  • 返回语义相近但编号不同的文档
  • 场景：订单号、身份证号、专有名词

失效类型 B：多跳推理

  • 查询："苹果 CEO 的母校创立于哪年？"
  • 跳1：苹果 CEO → Tim Cook
  • 跳2：Tim Cook 毕业于 → Auburn University
  • 跳3：Auburn University 创立于 → 1856年
根本原因 向量检索把"单个文档"映射为一个点。跨文档的链式推理需要的是图结构，而不是点集合的距离排序。

    dot = sum(x*y for x,y in zip(a,b))

    if na == 0 or nb == 0:

    return dot / (na * nb)

02 · BM25 关键词检索

2BM25 算法：比 TF-IDF 更实用的关键词排序

BM25（Best Match 25）是 Elasticsearch、OpenSearch 默认的全文检索算法，1994年提出，至今仍是工业标准。

BM25(q, d) = Σ IDF(t) × [ tf(t,d) × (k₁+1) ] / [ tf(t,d) + k₁ × (1 - b + b × |d|/avgdl) ] 其中: IDF(t) = log( (N - df(t) + 0.5) / (df(t) + 0.5) + 1 ) tf(t,d) = 词项 t 在文档 d 中的出现次数 |d| = 文档 d 的词项总数 avgdl = 语料库平均文档长度 k₁ = 词频饱和参数，通常 1.2–2.0 (默认 1.5) b = 文档长度归一化，通常 0.75

与 TF-IDF 的关键区别

  • TF 饱和：同一词出现100次 vs 10次差距被压缩
  • 文档长度归一化：短文档不因词频密度被过度奖励
  • IDF 下限平滑：避免出现负 IDF 值

擅长的场景

  • 精确关键词：合同号、人名、专有术语
  • 布尔逻辑："A AND B NOT C"类查询
  • 短文档检索：标题、代码标识符
  • 冷启动（无需训练，无需 embedding）

# BM25 从零实现 — 纯 Python，无第三方库
import math
from collections import Counter

class BM25:
    def __init__(self, corpus: list[str], k1: float = 1.5, b: float = 0.75):
        self.k1 = k1
        self.b  = b
        self.corpus = corpus
        self.N = len(corpus)

        # 分词
        self.tokenized = [doc.lower().split() for doc in corpus]
        self.doc_lens  = [len(toks) for toks in self.tokenized]
        self.avgdl     = sum(self.doc_lens) / self.N

        # 文档频率
        self.df: dict[str, int] = {}
        for toks in self.tokenized:
            for t in set(toks):
                self.df[t] = self.df.get(t, 0) + 1

        # 每篇文档的词频
        self.tf_per_doc = [Counter(toks) for toks in self.tokenized]

    def idf(self, term: str) -> float:
        df = self.df.get(term, 0)
        return math.log((self.N - df + 0.5) / (df + 0.5) + 1)

    def score(self, query: str, doc_idx: int) -> float:
        terms = query.lower().split()
        tf_map = self.tf_per_doc[doc_idx]
        dl     = self.doc_lens[doc_idx]
        score  = 0.0
        for t in terms:
            tf  = tf_map.get(t, 0)
            idf = self.idf(t)
            numerator   = tf * (self.k1 + 1)
            denominator = tf + self.k1 * (1 - self.b + self.b * dl / self.avgdl)
            score += idf * (numerator / denominator)
        return score

    def search(self, query: str, top_k: int = 5) -> list[tuple[float, str]]:
        scores = [(self.score(query, i), doc) for i, doc in enumerate(self.corpus)]
        scores.sort(reverse=True)
        return scores[:top_k]

from rank_bm25 import BM25Okapi
from typing import Optional
import re

class BM25Retriever:
    """生产级 BM25 检索器，带预处理和结果归一化。"""

    def __init__(self, docs: list[str]):
        self.docs = docs
        tokenized = [self._tokenize(d) for d in docs]
        self.bm25 = BM25Okapi(tokenized)

    @staticmethod
    def _tokenize(text: str) -> list[str]:
        """简单分词：小写 + 去标点 + 按空格分割。"""
        text = text.lower()
        text = re.sub(r'[^\w\s]', ' ', text)
        return text.split()

    def search(
        self,
        query: str,
        top_k: int = 10,
        score_threshold: Optional[float] = None,
    ) -> list[dict]:
        """
        返回 top_k 个结果，每个结果包含 doc、score、rank。
        score_threshold: 若设置，只返回得分高于阈值的结果。
        """
        tokenized_query = self._tokenize(query)
        scores = self.bm25.get_scores(tokenized_query)

        results = sorted(
            enumerate(scores), key=lambda x: x[1], reverse=True
        )[:top_k]

        output = []
        for rank, (idx, score) in enumerate(results, 1):
            if score_threshold is not None and score < score_threshold:
                break
            output.append({
                "rank":  rank,
                "score": float(score),
                "doc":   self.docs[idx],
                "index": idx,
            })
        return output


# ===== 与 LangChain 集成示例 =====
from langchain_core.documents import Document

def bm25_retrieve(
    query: str,
    documents: list[Document],
    top_k: int = 5,
) -> list[Document]:
    """直接接受 LangChain Document 对象的 BM25 检索函数。"""
    retriever = BM25Retriever([doc.page_content for doc in documents])
    results = retriever.search(query, top_k=top_k)
    return [documents[r["index"]] for r in results]
03 · 知识图谱 + Neo4j

3什么是知识图谱（具体例子）

知识图谱是一种以节点（实体）和边（关系）存储信息的数据库。它让"多跳推理"变成一次图遍历。

知识图谱示例：科技公司 CEO 与教育背景

  (Apple Inc)──[:CEO_OF {since:"2011"}]──▶(Tim Cook)
                                               │
                                    [:GRADUATED_FROM]
                                               │
                                               ▼
                              (Auburn University)──[:FOUNDED_IN]──▶(1856)
                                               │
                                    [:LOCATED_IN]
                                               │
                                               ▼
                                     (Auburn, Alabama)

  (Apple Inc)──[:FOUNDED_BY]──▶(Steve Jobs)──[:FOUNDED]──▶(Pixar)
  (Apple Inc)──[:FOUNDED_BY]──▶(Steve Wozniak)
  (Apple Inc)──[:HEADQUARTERED_IN]──▶(Cupertino)

多跳查询："苹果CEO的母校创立于哪年？"
MATCH (company:Company {name:"Apple Inc"})
      -[:CEO_OF]-(person:Person)
      -[:GRADUATED_FROM]->(school:University)
      -[:FOUNDED_IN]->(year)
RETURN year.value
→ 1856   （3跳，毫秒级完成）
图 vs 向量数据库的核心差异 向量数据库存储"文本的压缩表示"，图数据库存储"显式的命名关系"。图查询是确定性的，向量查询是概率性的。

from neo4j import GraphDatabase, Driver
from contextlib import contextmanager
import os
import logging

log = logging.getLogger(__name__)

class Neo4jClient:
    """
    生产级 Neo4j 客户端。
    关键：Driver 是线程安全且带连接池的，整个应用只创建一次。
    """

    def __init__(
        self,
        uri: str | None = None,
        username: str | None = None,
        password: str | None = None,
        max_connection_pool_size: int = 50,
    ):
        self._uri      = uri      or os.environ["NEO4J_URI"]
        self._username = username or os.environ.get("NEO4J_USERNAME", "neo4j")
        self._password = password or os.environ["NEO4J_PASSWORD"]

        # 关键：Driver 内置连接池，整个进程只创建一次
        self._driver: Driver = GraphDatabase.driver(
            self._uri,
            auth=(self._username, self._password),
            max_connection_pool_size=max_connection_pool_size,
        )
        self._driver.verify_connectivity()
        log.info("Neo4j connected: %s", self._uri)

    def close(self):
        self._driver.close()

    @contextmanager
    def session(self, database: str = "neo4j"):
        """Context manager for session lifecycle."""
        sess = self._driver.session(database=database)
        try:
            yield sess
        finally:
            sess.close()

    def run_read(self, query: str, **params) -> list[dict]:
        """Execute a read-only Cypher query, return list of dicts."""
        with self.session() as sess:
            result = sess.execute_read(
                lambda tx: list(tx.run(query, **params))
            )
        return [dict(record) for record in result]

    def run_write(self, query: str, **params) -> None:
        """Execute a write Cypher query in a transaction."""
        with self.session() as sess:
            sess.execute_write(
                lambda tx: tx.run(query, **params)
            )

    def setup_indexes(self) -> None:
        """Create indexes for fast node lookups. Run once at startup."""
        indexes = [
            "CREATE INDEX entity_id IF NOT EXISTS FOR (n:__Entity__) ON (n.id)",
            "CREATE INDEX person_name IF NOT EXISTS FOR (n:Person) ON (n.name)",
            "CREATE INDEX company_name IF NOT EXISTS FOR (n:Company) ON (n.name)",
            "CREATE INDEX university_name IF NOT EXISTS FOR (n:University) ON (n.name)",
        ]
        for idx in indexes:
            self.run_write(idx)
        log.info("Neo4j indexes created")

04 · LangChain GraphRAG Pipeline

4LLMGraphTransformer：文本 → 知识图谱

LangChain 的 LLMGraphTransformer 用 LLM 从非结构化文本中自动抽取实体和关系，直接写入 Neo4j。

LLMGraphTransformer 工作流程:

输入文本:
  "Tim Cook, the CEO of Apple Inc, graduated from Auburn University
   in 1982 with a degree in Industrial Engineering."

LLM 抽取 (few-shot prompt):
  节点:  Tim Cook (Person)
         Apple Inc (Company)
         Auburn University (University)
         Industrial Engineering (Field)

  关系:  Tim Cook --[CEO_OF]--> Apple Inc
         Tim Cook --[GRADUATED_FROM]--> Auburn University
         Tim Cook --[STUDIED]--> Industrial Engineering
         Auburn University --[LOCATED_IN]--> Alabama

写入 Neo4j:
  MERGE (n:Person {id:"Tim Cook"}) SET n.name="Tim Cook"
  MERGE (n:Company {id:"Apple Inc"}) SET n.name="Apple Inc"
  MERGE (a)-[:CEO_OF]->(b) ...

注意: LLM 可能产生幻觉实体 → 用 allowed_nodes/allowed_relationships 约束

        graph_docs,

        include_source=True,    # 保留原始文档引用（溯源用）

    return node_count

05 · RRF 融合排序

5RRF：Reciprocal Rank Fusion

RRF 由 Cormack et al. 2009 年提出，是目前最简单且最有效的多路检索融合方法。

RRF_score(d) = Σᵢ 1 / (k + rankᵢ(d)) 其中: d = 文档 k = 常数，默认 60（防止头部排名被过度放大） rankᵢ(d) = 文档 d 在第 i 路检索中的排名（从1开始） Σ = 对所有包含 d 的检索列表求和 示例 (k=60): 文档 A 在向量检索排名 #1 → 1/(60+1) = 0.01639 文档 A 在 BM25 排名 #3 → 1/(60+3) = 0.01587 文档 A 未出现在图检索中 → 0 文档 A 的 RRF 总分 = 0.01639 + 0.01587 = 0.03226
为什么 k=60？ k 控制"排名灵敏度"。k 太小（如 1）：排名差1位导致分数悬殊，不鲁棒。k 太大（如 1000）：所有文档分数趋同，失去区分度。60 是原论文在大量信息检索基准上验证的最优默认值。

def rrf_score(ranked_lists: list[list[str]], k: int = 60) -> dict[str, float]:
    """计算每个文档的 RRF 得分。"""
    scores: dict[str, float] = {}
    for ranked in ranked_lists:
        for rank, doc_id in enumerate(ranked, start=1):
            scores[doc_id] = scores.get(doc_id, 0.0) + 1.0 / (k + rank)
    return scores

# 计算各路单独的"分数"（用排名的倒数表示）
def single_score(ranked: list[str], k: int = 60) -> dict[str, float]:
    return {doc: 1.0/(k+rank) for rank, doc in enumerate(ranked, 1)}

06 · 完整混合检索 Pipeline

6端到端混合检索系统

将向量检索、BM25、图检索和 RRF 融合组装成一个可复用的生产类：

hybrid_retriever.py Display 
"""
混合检索系统：ChromaDB (向量) + BM25 (关键词) + Neo4j (图谱) + RRF 融合
pip install langchain langchain-openai langchain-community
            chromadb rank-bm25 neo4j
"""
from __future__ import annotations

import logging
import os
import re
from dataclasses import dataclass, field
from typing import Optional

import chromadb
from langchain_core.documents import Document
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from neo4j import GraphDatabase
from rank_bm25 import BM25Okapi

log = logging.getLogger(__name__)


@dataclass
class RetrievalResult:
    doc_id:  str
    content: str
    source:  str          # "vector" | "bm25" | "graph"
    score:   float = 0.0
    rank:    int   = 0
    metadata: dict = field(default_factory=dict)


class HybridRetriever:
    """
    三路混合检索器: ChromaDB + BM25 + Neo4j，RRF 融合。

    使用方式:
        retriever = HybridRetriever.from_env()
        retriever.add_documents(docs)
        results = retriever.search("苹果CEO的母校创立于哪年？", top_k=5)
    """

    def __init__(
        self,
        chroma_collection: str = "hybrid_rag",
        neo4j_uri: str | None = None,
        neo4j_user: str = "neo4j",
        neo4j_password: str | None = None,
        embed_model: str = "text-embedding-3-small",
        rrf_k: int = 60,
    ):
        self.rrf_k = rrf_k
        self._docs: list[Document] = []

        # --- ChromaDB ---
        self._chroma = chromadb.Client()
        self._collection = self._chroma.get_or_create_collection(chroma_collection)
        self._embeddings = OpenAIEmbeddings(model=embed_model)

        # --- BM25 (rebuilt on each add_documents call) ---
        self._bm25: BM25Okapi | None = None
        self._bm25_corpus: list[str] = []

        # --- Neo4j ---
        _neo4j_uri = neo4j_uri or os.environ.get("NEO4J_URI", "")
        _neo4j_pw  = neo4j_password or os.environ.get("NEO4J_PASSWORD", "")
        self._neo4j_driver = None
        if _neo4j_uri and _neo4j_pw:
            try:
                self._neo4j_driver = GraphDatabase.driver(
                    _neo4j_uri, auth=(neo4j_user, _neo4j_pw),
                    max_connection_pool_size=20,
                )
                self._neo4j_driver.verify_connectivity()
                log.info("Neo4j connected: %s", _neo4j_uri)
            except Exception as e:
                log.warning("Neo4j unavailable, graph retrieval disabled: %s", e)

    @classmethod
    def from_env(cls) -> "HybridRetriever":
        return cls()

    # ===== Indexing =====

    def add_documents(self, docs: list[Document]) -> None:
        """
        摄入文档：同时建立向量索引和 BM25 索引。
        图谱索引通过单独调用 build_graph() 完成。
        """
        self._docs.extend(docs)
        texts = [d.page_content for d in docs]

        # Embed + store in ChromaDB
        vectors = self._embeddings.embed_documents(texts)
        self._collection.add(
            ids=[f"doc_{len(self._docs)-len(docs)+i}" for i in range(len(docs))],
            embeddings=vectors,
            documents=texts,
            metadatas=[d.metadata for d in docs],
        )

        # Rebuild BM25 index
        self._bm25_corpus = [d.page_content for d in self._docs]
        tokenized = [self._tokenize(t) for t in self._bm25_corpus]
        self._bm25 = BM25Okapi(tokenized)
        log.info("Indexed %d documents (total: %d)", len(docs), len(self._docs))

    @staticmethod
    def _tokenize(text: str) -> list[str]:
        return re.sub(r'[^\w\s]', ' ', text.lower()).split()

    # ===== Retrieval =====

    def _vector_search(self, query: str, top_k: int) -> list[RetrievalResult]:
        q_vec = self._embeddings.embed_query(query)
        res = self._collection.query(
            query_embeddings=[q_vec], n_results=min(top_k, len(self._docs))
        )
        results = []
        for i, (doc_id, text, dist) in enumerate(zip(
            res["ids"][0], res["documents"][0], res["distances"][0]
        )):
            results.append(RetrievalResult(
                doc_id=doc_id, content=text,
                source="vector", score=1 - dist, rank=i + 1,
            ))
        return results

    def _bm25_search(self, query: str, top_k: int) -> list[RetrievalResult]:
        if not self._bm25:
            return []
        scores = self._bm25.get_scores(self._tokenize(query))
        ranked = sorted(enumerate(scores), key=lambda x: x[1], reverse=True)[:top_k]
        return [
            RetrievalResult(
                doc_id=f"doc_{idx}", content=self._bm25_corpus[idx],
                source="bm25", score=float(score), rank=rank + 1,
            )
            for rank, (idx, score) in enumerate(ranked)
        ]

    def _graph_search(self, query: str, top_k: int) -> list[RetrievalResult]:
        if not self._neo4j_driver:
            return []
        # 用 LLM 提取查询中的实体名，然后做图遍历
        cypher = """
        CALL db.index.fulltext.queryNodes('entity_fulltext', $query)
        YIELD node, score
        MATCH (node)-[r*1..2]-(related)
        RETURN node.name AS source_entity,
               type(r[0]) AS rel_type,
               related.name AS target_entity,
               score
        ORDER BY score DESC LIMIT $limit
        """
        results = []
        try:
            with self._neo4j_driver.session() as sess:
                records = sess.run(cypher, query=query, limit=top_k)
                for rank, rec in enumerate(records, 1):
                    content = (f"{rec['source_entity']} "
                               f"-[{rec['rel_type']}]-> "
                               f"{rec['target_entity']}")
                    results.append(RetrievalResult(
                        doc_id=f"graph_{rank}", content=content,
                        source="graph", score=float(rec["score"]), rank=rank,
                    ))
        except Exception as e:
            log.warning("Graph search failed: %s", e)
        return results

    # ===== RRF Fusion =====

    def _rrf_fusion(
        self,
        result_lists: list[list[RetrievalResult]],
    ) -> list[RetrievalResult]:
        """Merge multiple ranked lists using RRF."""
        rrf_scores: dict[str, float] = {}
        best_result: dict[str, RetrievalResult] = {}

        for ranked in result_lists:
            for item in ranked:
                rrf_scores[item.doc_id] = (
                    rrf_scores.get(item.doc_id, 0.0) + 1.0 / (self.rrf_k + item.rank)
                )
                if item.doc_id not in best_result:
                    best_result[item.doc_id] = item

        fused = sorted(rrf_scores.items(), key=lambda x: x[1], reverse=True)
        output = []
        for rank, (doc_id, score) in enumerate(fused, 1):
            result = best_result[doc_id]
            output.append(RetrievalResult(
                doc_id=doc_id, content=result.content,
                source=result.source, score=score, rank=rank,
                metadata=result.metadata,
            ))
        return output

    # ===== Public Interface =====

    def search(
        self,
        query: str,
        top_k: int = 5,
        use_graph: bool = True,
    ) -> list[RetrievalResult]:
        """
        三路检索 + RRF 融合。
        返回融合后的 top_k 结果。
        """
        per_source_k = top_k * 3  # 每路多取，给 RRF 更多候选

        vector_res = self._vector_search(query, per_source_k)
        bm25_res   = self._bm25_search(query, per_source_k)
        graph_res  = self._graph_search(query, per_source_k) if use_graph else []

        all_lists = [r for r in [vector_res, bm25_res, graph_res] if r]
        if not all_lists:
            return []

        fused = self._rrf_fusion(all_lists)
        return fused[:top_k]

    def answer(
        self,
        query: str,
        top_k: int = 5,
        model: str = "gpt-4o-mini",
    ) -> dict:
        """
        完整 RAG：检索 + 生成答案。
        """
        results = self.search(query, top_k=top_k)
        context = "\n\n".join(
            f"[{r.source.upper()} #{r.rank}] {r.content}"
            for r in results
        )
        llm = ChatOpenAI(model=model, temperature=0.1)
        messages = [
            {"role": "system", "content": (
                "你是知识库助手。根据提供的上下文回答问题。"
                "如果上下文不足以回答，明确说明。"
            )},
            {"role": "user", "content": f"上下文:\n{context}\n\n问题: {query}"},
        ]
        response = llm.invoke(messages)
        return {
            "answer":   response.content,
            "sources":  results,
            "context":  context,
        }

class OpenSearchHybridRetriever:
    """
    AWS OpenSearch Serverless 混合检索器。
    单个 index 同时支持 BM25 全文搜索和 k-NN 向量搜索。
    """

    def __init__(
        self,
        endpoint: str,
        index_name: str = "hybrid_rag",
        region: str = "ap-southeast-2",
    ):
        self.index_name = index_name
        self.embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

        # AWS SigV4 签名认证（OpenSearch Serverless）
        credentials = boto3.Session().get_credentials()

        )

            use_ssl=True,
            verify_certs=True,
            connection_class=RequestsHttpConnection,
        )

    def create_index(self) -> None:
        """创建同时支持全文搜索和向量搜索的 index。"""
        mapping = {
            "settings": {
                "index": {
                    "knn": True,
                    "knn.algo_param.ef_search": 512,
                }
            },
            "mappings": {
                "properties": {
                    "content": {"type": "text"},            # BM25 全文索引
                    "content_vector": {                     # k-NN 向量索引
                        "type": "knn_vector",
                        "dimension": EMBED_DIM,
                        "method": {
                            "name": "hnsw",
                            "space_type": "cosinesimil",
                            "engine": "faiss",
                        },
                    },
                    "doc_id":   {"type": "keyword"},
                    "metadata": {"type": "object", "enabled": False},
                }
            },
        }
        if not self.client.indices.exists(self.index_name):
            self.client.indices.create(self.index_name, body=mapping)

    def index_documents(self, docs: list[dict]) -> None:
        """批量索引文档（包含文本和向量）。"""
        texts = [d["content"] for d in docs]
        vectors = self.embeddings.embed_documents(texts)

        bulk_body = []
        for doc, vec in zip(docs, vectors):
            bulk_body.append({"index": {"_index": self.index_name, "_id": doc["doc_id"]}})
            bulk_body.append({
                "content":        doc["content"],
                "content_vector": vec,
                "doc_id":         doc["doc_id"],
                "metadata":       doc.get("metadata", {}),
            })
        self.client.bulk(bulk_body)

    def hybrid_search(self, query: str, top_k: int = 5) -> list[dict]:
        """
        混合查询：同时执行 BM25 全文搜索 + k-NN 向量搜索，
        使用 OpenSearch 原生 RRF 融合（OpenSearch 2.11+）。
        """
        q_vec = self.embeddings.embed_query(query)

        # OpenSearch hybrid query with RRF
        body = {
            "size": top_k,
            "query": {
                "hybrid": {
                    "queries": [
                        # BM25 全文查询
                        {"match": {"content": {"query": query}}},
                        # k-NN 向量查询
                        {"knn": {"content_vector": {"vector": q_vec, "k": top_k * 2}}},
                    ]
                }
            },
            "search_pipeline": {
                "phase_results_processors": [{
                    "normalization-processor": {
                        "normalization": {"technique": "min_max"},
                        "combination": {"technique": "arithmetic_mean"},
                    }
                }]
            }
        }
        response = self.client.search(index=self.index_name, body=body)
        return [
            {
                "doc_id":  hit["_source"]["doc_id"],
                "content": hit["_source"]["content"],
                "score":   hit["_score"],
            }
            for hit in response["hits"]["hits"]
        ]

    def bm25_only(self, query: str, top_k: int = 5) -> list[dict]:

@app.post("/search", response_model=SearchResponse)
async def search(
    body: SearchRequest,
    request: Request,
    x_request_id: Optional[str] = Header(default=None),
):
    req_id = x_request_id or str(uuid.uuid4())
    t0 = time.monotonic()

    retriever = request.app.state.retriever
    log.info('{"request_id":"%s","query":"%s","top_k":%d}',
             req_id, body.query[:60], body.top_k)

    # 并发执行三路检索（失败的路径返回空列表，不抛异常）
    async def safe_vector():
        try:
            loop = asyncio.get_event_loop()
            return await loop.run_in_executor(
                None, retriever._vector_search, body.query, body.top_k * 3
            )
        except Exception as e:
            log.warning("vector search failed: %s", e)
            return []

    async def safe_bm25():
        if not body.use_bm25:
            return []
        try:
            loop = asyncio.get_event_loop()
            return await loop.run_in_executor(
                None, retriever._bm25_search, body.query, body.top_k * 3
            )
        except Exception as e:
            log.warning("bm25 search failed: %s", e)
            return []

    async def safe_graph():
        if not body.use_graph:
            return []
        try:
            loop = asyncio.get_event_loop()
            return await loop.run_in_executor(
                None, retriever._graph_search, body.query, body.top_k * 3
            )
        except Exception as e:
            log.warning("graph search failed: %s", e)
            return []

    # 三路并发
    vector_res, bm25_res, graph_res = await asyncio.gather(
        safe_vector(), safe_bm25(), safe_graph()
    )

    # RRF 融合
    all_lists = [r for r in [vector_res, bm25_res, graph_res] if r]
    if not all_lists:
        raise HTTPException(status_code=503, detail="All retrieval sources failed")

    fused = retriever._rrf_fusion(all_lists)[:body.top_k]

    # 生成答案
    context = "\n\n".join(
        f"[{r.source.upper()} #{r.rank}] {r.content}" for r in fused
    )
    from langchain_openai import ChatOpenAI
    llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.1)
    messages = [
        {"role": "system", "content": "根据提供的上下文简洁回答问题。"},
        {"role": "user",   "content": f"上下文:\n{context}\n\n问题: {body.query}"},
    ]
    ai_msg = await llm.ainvoke(messages)
    answer = ai_msg.content

    latency = (time.monotonic() - t0) * 1000
    sources_used = list({r.source for r in fused})

    log.info('{"request_id":"%s","latency_ms":%.1f,"sources":%s}',
             req_id, latency, sources_used)

    return SearchResponse(
        request_id=req_id,
        query=body.query,
        results=[
            SearchResult(
                doc_id=r.doc_id, content=r.content,
                source=r.source, rrf_score=r.score, rank=r.rank,
            ) for r in fused
        ],
        answer=answer,
        latency_ms=round(latency, 1),
        sources_used=sources_used,
    )

12如何评估检索质量：NDCG + Recall@K

构建了混合检索系统之后，需要量化评估。两个核心指标：Recall@K（相关文档被检索到的比例）和 NDCG@K（考虑排名质量的归一化折损累积增益）。

Recall@K = |相关文档 ∩ 检索到的前K个文档| / |所有相关文档| NDCG@K = DCG@K / IDCG@K DCG@K = Σᵢ₌₁ᴷ relevance(i) / log₂(i+1) IDCG@K = 理想排序下的 DCG@K（所有相关文档排在最前面） relevance(i): 二元评分 {0, 1} 或分级评分 {0, 1, 2, 3} 直觉: - 排名#1 的文档权重 = 1/log₂(2) = 1.0 - 排名#2 的文档权重 = 1/log₂(3) ≈ 0.63 - 排名#5 的文档权重 = 1/log₂(6) ≈ 0.39 → 把相关文档排在前面比排在后面奖励更多

# 检索评估：Recall@K 和 NDCG@K，纯 Python 实现
import math

def recall_at_k(retrieved: list[str], relevant: set[str], k: int) -> float:
    """Recall@K: 前K个检索结果中包含多少相关文档。"""
    if not relevant:
        return 0.0
    retrieved_k = set(retrieved[:k])
    return len(retrieved_k & relevant) / len(relevant)

def dcg_at_k(retrieved: list[str], relevant: set[str], k: int) -> float:
    """Discounted Cumulative Gain @ K。"""
    score = 0.0
    for i, doc_id in enumerate(retrieved[:k], start=1):
        rel = 1.0 if doc_id in relevant else 0.0
        score += rel / math.log2(i + 1)
    return score

def ndcg_at_k(retrieved: list[str], relevant: set[str], k: int) -> float:
    """Normalized DCG @ K. Returns 0.0 if no relevant docs."""
    if not relevant:
        return 0.0
    actual_dcg = dcg_at_k(retrieved, relevant, k)
    # 理想排序：所有相关文档排在最前面
    ideal_retrieved = list(relevant)[:k]
    ideal_dcg = dcg_at_k(ideal_retrieved, relevant, k)
    return actual_dcg / ideal_dcg if ideal_dcg > 0 else 0.0

今天学了什么

  1. 向量检索的边界 — 精确匹配失效、多跳推理失效，理解失效原因
